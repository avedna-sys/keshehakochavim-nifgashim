# כשהכוכבים נפגשים

אסטרולוגיה של אהבה, משפחה וחברות — אפליקציה עצמאית בעברית וב־RTL.

## פיתוח

נדרש Node.js בגרסה 20.19 ומעלה או 22.12 ומעלה. סביבת הפיתוח נבדקה עם Node.js 24.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

שרת הפיתוח פועל בפורט 5173; שרת תצוגת הבנייה בפורט 4173.
בסביבה שבה תיקיית הבית אינה ניתנת לכתיבה, ניתן להוסיף ל־npm ci את הדגל `--cache /tmp/keshe-npm-cache`.

## מה קיים

טופסי פרטי לידה לשני אנשים, שעת לידה אופציונלית, בחירת קשר, בדיקת שדות, ומקום להעלאת תמונת היוצרת (JPG, PNG, WebP עד 5MB). שם האדם, תאריך ושעת הלידה והתמונה אינם נשלחים לשרת ואינם נשמרים באחסון קבוע. חיפוש המיקום שולח רק שם עיר וקוד מדינה לשירות Open-Meteo. תמונת היוצרת כלולה באתר; ניתן לבחור בממשק תמונה מקומית זמנית. אין תלות במאגר אחר.

## מבנה והמשך פיתוח

- `src/main.js`: ממשק ואירועי משתמש. אינו מייצר תוצאות אסטרולוגיות.
- `src/style.css`: עיצוב רספונסיבי ו־RTL, ללא תלות בגופנים או בשירותים חיצוניים.
- `src/synastry.js`: גבול הנתונים עבור מנוע עתידי. מחזיר בקשה עם סטטוס פיתוח בלבד.
- `tests/synastry.test.js`: בדיקות אימות פרטים והיעדר תוצאות חישוב מדומות.

מפת סינסטרי כפולה, טבלת היבטים ופרשנות מסומנות **בפיתוח**. הכפתור מאמת קלט בלבד. הוכנה שכבת מיקום והמרת זמן היסטורי, אך השירות החי ודיוק הנתונים דורשים אימות. בהמשך יש לחבר מנוע אפמריס אסטרונומי מדויק, כללי בתים והיבטים, רכיב מפה כפולה ושכבת פרשנויות בעברית. שעת לידה לא ידועה חייבת להישמר כחוסר מידע, בלי להמציא אופק או בתים. אין צורך במפתחות API לשלב הנוכחי.

## פרסום ב־Vercel

האפליקציה היא אתר סטטי ב־Vite. קובץ `vercel.json` מגדיר התקנה באמצעות `npm ci`, בנייה באמצעות `npm run build` ופלט בתיקיית `dist`. גרסת Node.js מוגדרת ל־24.x ב־`package.json`. אין צורך בשרת backend או במסד נתונים. חיפוש הערים משתמש בשירות החיצוני Open-Meteo, שאינו דורש מפתח לשימוש פיתוח לא מסחרי; יש לבדוק את תנאי הספק לשימוש מסחרי. אין נתיבי צד־לקוח נוספים המחייבים כללי rewrite.

ההגדרות לפרויקט חדש ונפרד ב־Vercel:

| הגדרה | ערך |
| --- | --- |
| Repository | `avedna-sys/keshehakochavim-nifgashim` |
| Root Directory | שורש המאגר (`./`), לא תיקיית `/workspace` |
| Framework Preset | Vite |
| Node.js Version | 24.x |
| Install Command | `npm ci` |
| Build Command | `npm run build` |
| Output Directory | `dist` |

לפני פרסום, יש לשמור ב־Git ולהעלות ל־GitHub את קובצי האפליקציה, קובץ הנעילה והגדרות הפריסה. לאחר אישור לפרסום, יש לייבא את המאגר הזה כפרויקט חדש ב־Vercel, לבדוק את ההגדרות וללחוץ Deploy. אין לקשר לפרויקט Vercel קיים של אפליקציה אחרת. לחיצה על Deploy מתחילה פריסה; אין צורך להריץ אותה במהלך ההכנה. אם המאגר כבר מחובר לפריסה אוטומטית, גם העלאת commit עשויה להתחיל פריסה — יש לבדוק זאת לפני push.

אחרי פרסום יש לבדוק את הדף בעברית וב־RTL במחשב ובנייד, טעינת קובצי העיצוב והקוד, אימות טופסי הלידה והודעת „בפיתוח”, והעלאת תמונה מקומית. העלאת תמונת היוצרת בממשק אינה משנה את האתר לצופים אחרים; לפרסום תמונה קבועה נדרש להוסיף תמונה מורשית כחלק מקובצי האתר.

## קובצי המיתוג

הלוגו המרכזי נמצא בקובץ `public/synastry-logo.png`, שהועבר מהקובץ „שני הגלגלים.png” ללא שינוי בתמונה. הוא מוצג בשלמותו, ללא חיתוך, ביחס המקורי 3:2 ובגודל מותאם למחשב ולנייד. שם האפליקציה וכותרת המשנה נשארים כטקסט נפרד. רקע המשבצות האפור מוטבע בתמונת המקור; הקובץ אינו שקוף. `public/logo.svg` נשאר כאייקון האתר.

תמונת היוצרת המקורית נמצאת ב־`public/creator-portrait.png`, שהועברה מהקובץ „עדנה תמונת פרופיל.png” ללא שינוי בקובץ או בתווי הפנים. היא מוצגת בפינה הימנית העליונה במסגרת זהובה עגולה: 64 פיקסלים במחשב ו־52 בנייד, ללא מתיחה. בחירת תמונה מקומית עדיין זמינה ומחליפה את התצוגה רק בדפדפן הנוכחי; לאחר רענון חוזרת תמונת ברירת המחדל.

רקע האתר משתמש בתמונה המקורית `public/background.jpg` (הועברה מהקובץ „כחול.jpg”). התמונה חוזרת בפרופורציות המקוריות במחשב ובנייד, עם שכבת ריכוך קלה. הטפסים ואזורי המפה, ההיבטים והפרשנות נמצאים על משטחים בהירים ואחידים; התמונה אינה משולבת בתוכם.


## מדינות, קואורדינטות וזמן לידה היסטורי

- שני שדות המדינה כוללים חיפוש בעברית באמצעות `datalist`, על בסיס רשימת ISO 3166-1 ב־`i18n-iso-countries`: 249 מדינות וטריטוריות ועוד קוסובו (XK). נשמר קוד מדינה יציב לצד השם בעברית. טקסט חופשי שאינו מדינה מוכרת אינו מתקבל.
- בוחרים מדינה, מקלידים לפחות שתי אותיות בעיר הלידה ובוחרים אחת מהתוצאות. מוצגים מחוז וקואורדינטות כדי להבחין בין ערים בעלות שם זהה. אפשר לחפש גם באיות לטיני אם חסר שם עברי בנתוני המקור. אין בחירה אוטומטית בתוצאה הראשונה ואין שימוש בעיר בירה כברירת מחדל.
- `src/birth-location.js` משתמש ב־`https://geocoding-api.open-meteo.com/v1/search`, עם `countryCode`, `language=he`, שם העיר בלבד ו־`credentials: omit`. נתוני המקור הם GeoNames. תשובות ללא קואורדינטות או מזהה IANA תקין, או שאינן במדינה שנבחרה, אינן ניתנות לבחירה.
- שינוי המדינה או טקסט העיר מבטל בחירה ישנה; בקשות ישנות מבוטלות ותשובות מאוחרות אינן מחליפות חיפוש חדש. תקלה/תוצאה חסרה מונעות הכנת בקשה עם מיקום משוער.
- `createBirthContext` הוא נקודת החיבור למנוע עתידי: `location` כולל `countryCode`, `latitude`, `longitude`, `timeZone`, מזהה עיר ומקור. `civilTime` כולל רגע UTC והיסט לפי תאריך ושעת הלידה המקומיים. השדות המקוריים שם/תאריך/שעה/מקום/מדינה נשמרים.
- המרת השעה משתמשת ב־Temporal ובכללי IANA של סביבת הריצה, ולא בהיסט UTC עכשווי או אחיד למדינה. שעת לידה לא ידועה נשארת חסרה. שעה כפולה בחזרה משעון קיץ או שעה שאינה קיימת בקפיצה קדימה מזוהות ונחסמות לפני הכנת בקשת חישוב; יש לברר את רישום הלידה במקום לבחור שרירותית.
- קואורדינטות התוצאה הן מיקום יישוב בנתוני הספק, לא כתובת בית החולים. מזהה אזור הזמן של יישוב וכללי IANA אינם תעודת דיוק היסטורית: בפרט לפני 1970, בשינויי גבולות וביישובים חסרים נדרש אימות מול מקורות היסטוריים. גרסת כללי הזמן נקבעת על ידי הדפדפן/ICU ויש לעדכנה. אין במאגר מנוע אסטרונומי פעיל; חישובים לא נוספו ולא הוחלפו.

### שירות חיצוני ובדיקות

חיפוש המיקומים דורש HTTPS ל־`geocoding-api.open-meteo.com` ותמיכה בגישה מהדפדפן. השירות החינמי מיועד לפיתוח/שימוש לא מסחרי לפי [תנאי הספק](https://github.com/open-meteo/geocoding-api#terms--privacy); שימוש מסחרי דורש הסדר מתאים או החלפת ספק. הקרדיט ל־Open-Meteo ול־GeoNames מוצג בממשק.

בסביבת הענן הנוכחית בדיקת השירות החי הוחזרה ב־403 עקב מדיניות הרשת; נדרשת החלת תוספת הדומיין בהגדרות הסביבה ובדיקה חוזרת. תשובות API נבדקו בבדיקות יחידה ובדפדפן באמצעות תשובות מבוקרות בלבד, ואין לראות בכך אימות של זמינות השירות החי או הכיסוי הגאוגרפי שלו. רשימת המדינות והמרת הזמן נבדקות מקומית ואינן דורשות רשת. בדיקות הזמן מכסות כללי שעון היסטוריים בישראל, פער/כפילות בשעון, יום שנדלג בסמואה והיסט לא שלם בנפאל.
