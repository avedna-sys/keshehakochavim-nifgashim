# שלב ד׳ — סינתזה לתקשורת ולרגשות בלבד

מימוש מחקר מקומי, שאינו מיובא לאפליקציה הפעילה. שלב ג׳ 0.2 נשאר פועל, ועותק להשוואה נשמר ב־../history/v0.2. אין שינוי במנוע החישוב, ב־TZDB, באורבים הגאומטריים או במפת הסינסטרי.

## זרימת המידע

`createSynthesisInterpretation(pair,{participants})` → `buildFindings` הקיים ואימות הזהויות/תפקידי המשפחה → `buildSynthesisPlan` → `composeSynthesis` + `interactionSynthesis` → פרקים, מקורות, יומן מושגים ועקבות הבחירה.

- plan.mjs מקצה כל היבט מחושב לפרק אחד; מרקורי–ירח מקבל עדיפות לרגשות כאשר הרלוונטיות שווה. בפרק האחר נרשמת הפניה, בלי פרשנות חוזרת לאותו יחס.
- compose.mjs מקבץ מגעים לצירי משמעות ומבדיל בין המוקד בשני האנשים. הקשר מזלי, בית לידה, בית האחר ושליטה מסורתית אינם ראיות עצמאיות ואינם נספרים כחיזוקים נפרדים.
- interactions.mjs מסנתז מפגשי תפקודים כגון בדיקה וחשיפה, שינוי ועשייה, או רגישות וניסוח. התנאים תלויים בגופים, סוג המגע ובעל התפקוד; אין תנאי על שם, תאריך או זוג בדיקה.
- לכל טענה מקורות facts, baseKeys, מדיניות ו־conceptKey. semanticLedger מונע רישום כפול של מושג מכוסה. אותו מיקום של שליט אינו מתואר מחדש כאשר הוא נושא תחום נוסף בפרק אחר.
- משפטי ההקשר המשפחתי/חברות תלויים במוקד ומוצגים פעם אחת לכל תפקיד רעיוני. בעלות על שבתאי אינה בעלות על סמכות הורית. אין הסקת מגדר, קטינות או תלות משם או מפה.

## מספר ממצאים וחשיבות

אין מכסה של שני היבטים. נבחנים כל המגעים הישירים למרקורי/ירח בין עשרת הגופים. מגעים סמוכים לסף המנוע אינם מובילים נרטיב. מגע שאינו סמוך לסף יכול להיכלל כהקשר משני גם כשהוא רחב. מגעי שליט בית 3/4 ללא גוף המוקד מצטרפים רק כאשר הצד האחר הוא גוף אישי, האורב עד 2° ויחס האורב לסף עד 0.35; שליט רגיש לגבול אינו בסיס יחיד לערוץ כזה.

הסיווג עריכתי, אינו מדד מדעי:

- מרכזי: מגע ישיר, יחס אורב/סף עד 0.35 או אורב מוחלט עד 1°.
- משני: מגע ישיר ביחס מעל 0.65. אינו מקבל טענת דפוס חזק.
- מחזק: ממצא כשיר נוסף שאינו עוגן מרכזי או משני; המשמעות היא הרחבת הקשר, לא ראיה סטטיסטית עצמאית.
- מאזן: מגע משולש/משושה שאינו משני, לצד מתח מרכזי בפרק. אינו מבטל את המתח ואינו נחשב אוטומטית לחוויה זהה בשני הכיוונים.
- צמידות היא מפגש תפקודים, ולא מסומנת אוטומטית כהרמוניה.

מספר ההיבטים הנבחרים כולל גם ערוצים דרך שליט, ולכן אינו מספר המגעים הישירים בלבד. האורבים המקוריים נשמרים. רגישות בתי הלידה וזמני הלידה נשארת מגבלה של כל פרשנות בתי המנוע; אין כאן אימות לכל תאריך או לכל מיקום בעולם.

## הרצה ותוצרים

מתוך research/astronomy-engine:

```
node interpretation/general/phase-d/build-review.mjs
node interpretation/general/phase-d/audit.mjs
node --test validation/phase-d-synthesis.check.mjs validation/general-interpretation.check.mjs validation/relationship-review.check.mjs
node validation/phase-d-browser.mjs
```

examples/case-1..3 כוללים את שני הפרקים המלאים, HTML עם מצבי פרשנות/מקורות, ו־JSON עם עקיבות. נתוני שלושת הזוגות סינתטיים ונוצרים מחדש מהמנוע. comparison.json ו־audit.json מתעדים את ההבדלים משלב ג׳.

מפת הזוג האישי מחושבת מחדש מתוך interpretation/private/reference-input.json בלבד. תוצאותיה נשמרות ב־interpretation/private/phase-d, שכבר מוחרגת מ־Git. אין לייבא את התוצאות האלה ל־src/public או לחבילת פרסום. בסביבה ללא קובץ אישי, ניסוי זה אינו יכול להשלים את הבדיקה האישית; אין לייצר עבורה נתונים.
