# תצוגת סינסטרי בדפדפן — ענף המחקר בלבד

התצוגה נפרדת מהאתר הקיים. כל הקוד בתיקיית `research/astronomy-engine`; אין שינוי ב־`src/`, ב־`public/`, בבניית האתר או בהגדרות הפרסום שלו. זהו ניסוי בחישובים שנבדקו בדגימות מול Swiss, ולא אישור לתאימות מקצועית מלאה עם Solar Fire.

## פתיחה

משורש המאגר, בענף `research/astronomy-engine`:

```sh
cd research/astronomy-engine
npm ci --cache /tmp/synastry-npm-cache
npm run dev:chart
```

פותחים **http://localhost:5174/**. בסביבת ענן יש לפתוח את פורט **5174** דרך Preview / Ports של הסביבה. כתובת localhost מתייחסת למחשב שמריץ את השרת; אין כאן כתובת אתר ציבורית חדשה. `index.html` אינו מיועד לפתיחה ב־file://.

לתצוגת הבנייה המקומית:

```sh
npm run build:chart
npm run preview:chart
```

פותחים **http://localhost:4174/**, או Preview של פורט **4174** בסביבת הענן. הפלט נכתב רק ל־`browser-dist/` שבתיקיית המחקר ומוחרג מ־Git. אין צורך ב־API חיצוני, במפתח שירות או בנתוני Swiss בזמן צפייה בדפדפן.

## מה רואים

הדף נפתח עם **נתוני לידה מסומנים לבדיקה**, לא פרטים של אנשים מזוהים: אדם ראשון, 17.5.1990 09:30 בירושלים; אדם שני, 8.10.1992 18:45 באמסטרדם. המיקומים, הצירים וההיבטים מחושבים בפועל מהמנוע — אינם תוצאות דמה. אפשר לשנות את הפרטים וללחוץ **צור מפת סינסטרי**. עריכת פרטי הלידה מסתירה מפה קודמת עד חישוב מוצלח חדש.

- שני גלגלי מזלות, סגול לאדם הראשון ותכלת לשני. המפה מסתובבת כך ש־ASC של הראשון בצד שמאל; שני האנשים באותה מערכת ייחוס טרופית.
- עשרת גרמי השמיים לכל אדם, 12 בתי Placidus לכל אדם ו־ASC/DSC/MC/IC בשני הצבעים.
- סמלים צפופים מופרדים כתוויות עם קווי מנחה. **הסימון המדויק בשפת הגלגל נשאר באורך המחושב**; האלגוריתם אינו משנה את נתוני המפה או את ההיבטים.
- קווי היבטים במרכז **בין האנשים בלבד**, וטבלה עם מרחק זוויתי ואורב בשש ספרות עשרוניות. לחיצה על “הדגשה” מדגישה את הקו במפה. אפשר לסנן לפי סוג.
- כללי האורב המפורשים לניסוי: צמידות ומולות 8°, ריבוע ומשולש 6°, משושה 4°. אלה בחירות מוצר, לא קבועים אסטרונומיים. סימון ≈ מזהה היבט נכלל הסמוך עד 2 דקות קשת לסף; קרוב לסף, אי־ודאות המנוע יכולה לשנות הכללה/אי־הכללה. אין קביעה של היבט מתקרב/מתרחק ללא בדיקת מהירויות.
- אפשר להוסיף Mean North/South Node ולילית ממוצעת מהמודולים שנבדקו. הם מזוהים בשמם; אין כירון, True Node, לילית אוסצולטורית או אסטרואיד Lilith.
- טבלאות בתים, צירים ומיקומי נקודות נגישות תחת סעיף הפירוט. בנייד ניתן להגדיל את המפה ולגלול אותה ואת הטבלאות.
- כפתור הורדת SVG שומר תמונת וקטור מקומית של המפה. אין העלאת פרטי לידה או תמונות לשרת חיצוני.

## זמן ומקום

שני הטפסים מזינים את ממיר IANA TZDB 2026b המלא, כולל backzone והיסטים בשניות, ואז את המנוע הקיים ללא שינוי בנוסחאותיו. אמסטרדם 1930 נשמרת ב־+00:19:32. שעה כפולה או חסרה אינה נפתרת אוטומטית ולא מפיקה מפה. שעת לידה ידועה נדרשת.

רשימת המקומות הקצרה היא רשימת ייחוס מפורשת לניסוי, עם מרכזי ערים וקואורדינטות קבועות. היא אינה שירות geocoding עולמי. אפשר להזין ידנית קואורדינטות ומזהה IANA; האחריות להתאמה ביניהם אינה נפתרת אוטומטית. שינוי ידני מסומן ככזה. הטווח 1800–2026; Placidus בקווי רוחב קוטביים נחסם, בלי מעבר שקט לשיטת בתים אחרת.

פרופיל הזמן נשאר הפרופיל שנבדק: DUT1=0 ומודל ΔT ברירת המחדל של Astronomy Engine. הנחות אלו מוצגות במסך. עדיין נדרש טיפול מקצועי מלא ב־UT1/TT, דיוק מקום הלידה ואי־ודאות ברישומי עבר לפני פרסום מוצר. מספר הספרות בטבלה אינו הבטחה לדיוק פיזיקלי זהה.

## בדיקות

```sh
npm run reference:prepare
npm run tzdb:prepare
npm test
npm run build:chart
```

לבדיקת דפדפן, בזמן ששרת הניסוי פועל, ובסביבה עם Chromium:

```sh
npm run test:browser
# לבדיקת הבנייה במקום שרת הפיתוח:
CHART_URL=http://127.0.0.1:4174 npm run test:browser
```

`CHROMIUM_PATH` מאפשר לבחור נתיב דפדפן אחר; ברירת המחדל בסביבת הענן היא `/usr/bin/chromium`. אין הורדה אוטומטית של דפדפן. צילומי המסך נכתבים לתיקיית `validation/reference-data/` המקומית והמוחרגת.

בדיקות חדשות כוללות: התאמה מלאה למנוע הקיים לאחר המרת אמסטרדם 1930; מניעת פלט לזמן כפול/חסר ולאזורי קוטב; חמשת ההיבטים, גבולות האורב וגלישת 0/360; כיוון SVG, מקור סימוני הכוכבים ופריסת 13 סמלים צפופים. בדיקת הדפדפן משווה את המיקומים למנוע Node, בודקת 20 כוכבים (26 סימונים עם הנקודות הממוצעות), 24 קצוות בתים, 8 צירים, התאמת טבלה לקווים, הדגשה, סינון, הורדת SVG, בטיחות שמות, מניעת מפה ישנה, מובייל ובקשות רשת מקומיות בלבד.

השוואת סינסטרי חדשה מול Swiss בדקה 100 זוגות מפות, 10,000 צמדי כוכבים ו־50,000 חישובי אורב (כולל מועמדים מחוץ לספי ההכללה), במועדי 1800–2026. הדוח המספרי נכתב ב־`validation/synastry-reference-results.json`; זהו מדגם, לא השוואה לכל הזוגות האפשריים.

תוצאות דפדפן: `validation/browser-results.json`. מגבלות ודיוק הליבה מפורטים גם בדוחות הכוכבים, הזמן, Mean Node ולילית. סוויטת החלק המאומת אינה כוללת את מועמד True Node הכושל שנשמר מקומית בנפרד.

אין לפרסם את תיקיית המחקר ב־Netlify בשלב זה. בניית האתר הציבורי נשארת בשורש המאגר ופונה לממשק המקורי.

## קובץ HTML עצמאי

אחרי `npm run build:chart`, מריצים `npm run export:chart`. מתקבל `browser-dist/synastry-preview.html`, הכולל את JavaScript, העיצוב ונתוני IANA בתוך קובץ אחד, ללא קריאות לשירותי צד שלישי. אפשר להורידו למחשב ולנסות לפתוח בדפדפן מקומי, או לפתוח `http://localhost:4174/synastry-preview.html` כשה־Preview פועל.

בסביבת הענן הדפדפן המנוהל חוסם ניווט ישיר ל־file:// (`ERR_BLOCKED_BY_ADMINISTRATOR`), ולכן אין לטעון שפתיחה ישירה של קובץ מקומי נבדקה כאן. אותו קובץ עצמאי נבדק דרך שרת HTTP המקומי, כולל התאמת המיקומים למנוע, שמירה כ־SVG ובדיקות מחשב/נייד. תוצאותיו ב־`validation/browser-standalone-results.json`.
