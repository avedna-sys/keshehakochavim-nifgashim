## הגדרת הייחוס

Swiss Ephemeris 2.10.03, קובצי אפמריס רשמיים מקובעים ל־4daf766ab1dec2316a65fcb5f5149e52b4cd9027, עם SHA-256 לפי reference-provenance.json. Moon state נקרא ב־TT, גאוצנטרי, גאומטרי, J2000, XYZ ומהירויות. דגלי הבקשה: 6514; דגלי אפמריס נבדקו כדי למנוע fallback. Swiss מוסיף אוטומטית NOABERR/NOGDEFL לבקשת TRUEPOS. ראש True להשוואה חושב גם בגרסה גאומטרית וגם בברירת המחדל apparent. אין שימוש ב־Swiss בזמן הרצת מודול ה־MIT.

נבדקו הגדרת המישור האוסצולטורי והטיפול במסגרת ב־lunar_osc_elem ו־swi_plan_for_osc_elem במקור Swiss המותקן לצורכי ייחוס בלבד. המהירות מסובבת פיזיקלית ואינה מקבלת מהירות של מסגרת הקואורדינטות. לא הועתק קוד Swiss למנוע. ההגדרה הווקטורית המקורית h=r×v ו־k×h לצומת העולה תקינה.

## העבודה המאומתת שנשמרת בנפרד

`verified/mean-node.mjs` הוא מודול עצמאי של Mean Node בלבד, ללא תלות בקוד המועמד וללא חיבור אוטומטי ל־engine.mjs או לאתר. הוא מחשב את ראש הדרקון הממוצע ואת הזנב ב־180° ממנו.

בבדיקה עצמאית חדשה של 6018 מועדים, 6018 קריאות Swiss ו־12036 בדיקות נגדיות, היו **0 חריגות**. סף Mean נשאר 0.001°. שיא ההפרש (ראש וזנב, שני המצבים): **0.000100240°**. בדיקות קלט ונגדיות עברו.

כל בדיקות הניסוי המאומת ניתנות להרצה ב־npm test. בדיקות True אינן חלק מהסוויטה המאושרת: הן נשארו יחד עם המועמד תחת local-investigations/true-node, מוחרגות מ־Git. אין לפרש את הצלחת הסוויטה המאומתת כהצלחת True Node. עדות הכישלון עצמה נשמרת ב־validation/true-node-failure-evidence.json.

## מה עוד נדרש

כדי לעמוד בסף True נדרש מקור/מודל מצב ירח מדויק יותר ברישיון מתאים, או שיפור מוכח במודל הקיים ואימות מחודש. אין להצמיד טבלת תיקון ל־Swiss, להחליף את True בממוצע, להחליק תנודות אמיתיות או להגדיל את הסף כדי לעבור. מדיניות UT1/TT וגבולות הנתונים ההיסטוריים נותרות נושאים נפרדים. main והאפליקציה הציבורית אינם משתנים.
