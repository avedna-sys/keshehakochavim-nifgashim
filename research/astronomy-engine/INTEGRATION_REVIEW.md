# שילוב סינסטרי — תצוגת מחקר לבדיקה

תאריך: 2026-10-20. ענף: `research/astronomy-engine`. אין פרסום, מיזוג או שינוי בענף main. קובצי המיתוג והעיצוב המקורי נשמרו. השינויים ב־src הם שילוב ניסיוני מאושר בענף המחקר בלבד.

## מה ניתן לבדוק

הטפסים המקוריים ושירות בחירת המדינות והערים נשמרו. נדרשת עיר שנבחרה עם קואורדינטות ומזהה IANA, ושעת לידה ידועה. ההמרה משתמשת ב־TZDB 2026b מלא כולל backzone והיסטים בשניות, ולא בנתוני Intl ההיסטוריים של הדפדפן. שעות חסרות או כפולות נדחות, בלי לבחור UTC שרירותי. שינוי בקלט מסיר תוצאה קודמת, גם בזמן טעינה.

המפה מחושבת מקומית: עשרת גרמי השמיים, גלגל מזלות טרופי, שני אנשים בצבעים נפרדים, 12 בתים לכל אדם ו־ASC/DSC/MC/IC. Mean Node וזנבו ולילית ממוצעת ניתנים לבחירה. אין True Node, כירון או פרשנות אוטומטית. אפשר לסנן ולהדגיש היבטים ולהוריד SVG. טבלאות כוללות מעלות ואורבים; ספרות התצוגה אינן הבטחה לדיוק פיזיקלי זהה.

כללי האורב: צמידות ומולות 8°, ריבוע ומשולש 6°, משושה 4°. סמלים צפופים מוזזים לתצוגה בלבד עם קו עזר לנקודה המדויקת. לא מחושבת הבחנה בין היבט מתקרב למתרחק.

## פתיחת התצוגה

קובץ `integrated-dist/website-preview.html` נוצר עם JavaScript, CSS, מסד הזמן ותמונות המיתוג מוטמעים. להוריד ולפתוח בדפדפן; לחיצה על **מילוי נתוני בדיקה** ממלאת נתוני קלט מסומנים מירושלים ואמסטרדם בלבד. לאחר מכן ללחוץ **צור מפת סינסטרי**. אלו קלטי בדיקה גלויים והחישוב מבוצע בפועל, לא תמונת מפה מוכנה או תוצאה מדומה. אפשר גם להזין פרטים ולבחור עיר דרך השירות החי.

הקובץ נבדק דרך HTTP מקומי. פתיחת file:// ישירה לא אומתה בדפדפן הענן, שחוסם גישה זו לפי מדיניות. אין כרגע קישור Preview חיצוני מאומת; localhost של שרת הענן אינו כתובת זמינה במחשב המשתמשת.

למפתח:

```sh
npm ci
npm test
npm run build
npm run dev -- --port 5175
# מתיקיית research/astronomy-engine, אחרי npm ci:
npm test
npm run test:integrated-browser
npm run build:integrated
npm run export:integrated
```

הפלט העצמאי וצילומי המסך נגזרים מהקוד ואינם נשמרים ב־Git. ניתן ליצור אותם מחדש בפקודות לעיל.

## תוצאות אמיתיות מהרצה זו

- 12 בדיקות האפליקציה עברו, 0 כישלונות; בניית Vite עברה.
- 21 בדיקות המחקר עברו מחדש: השוואת כוכבים/בתים ל־Swiss, המרות זמן, Mean Node, לילית ממוצעת והיבטים. תוצאות גולמיות ותאריכי הריצה נשמרו ב־validation/*results.json.
- בדיקות דפדפן לתצוגה המשולבת ולפלט העצמאי עברו: 20 סימוני כוכבים (26 עם נקודות רשות), 24 גבולות בתים, 8 צירים, התאמה למנוע עד 1e-8 מעלות, טבלה, הדגשה, הורדה, פרטיות בקשת העיר ושינוי קלט. 250 אפשרויות מדינה כולל רשומות ISO של טריטוריות, ו־5 סוגי קשר נשמרו.
- אמסטרדם 1930: ‎+00:19:32; שעה מקומית 12:00 הומרה ל־11:40:28Z. פער וכפילות בניו יורק ושעת לידה חסרה חסמו מפה כנדרש.
- שכבת הזמן: 11,034 מקרים, הפרש UTC מרבי 0 שניות מול Python הקורא את אותו מקור IANA. זו בדיקת המימוש, לא מקור היסטורי עצמאי.
- השוואת ההיבטים: 100 זוגות, 50,000 בדיקות אורב, הפרש מרבי 0.009640379715° מול Swiss, מתחת לסף שנקבע מראש 0.033333333333°; לא נמצאו הבדלי סיווג במדגם.
- המפה נבדקה במחשב ובמסך ברוחב 390 פיקסלים, כולל הגדלה וגלילה בתוך המפה/הטבלה, ללא גלישה של הדף.

## בדיקה חיה שלא הושלמה

שירות Open-Meteo ענה לבקשת HTTPS משורת הפקודה. בדיקת בחירת עיר חיה בדפדפן הענן נכשלה: `net::ERR_CERT_AUTHORITY_INVALID`, ולאחר מכן timeout. לא בוטלה בדיקת TLS ולא הוחלף שירות המיקומים. בדיקות הדפדפן המצליחות השתמשו בתשובות API מבוקרות; אינן הוכחה לזמינות השירות החי. הפרטים נשמרו ב־validation/integrated-live-results.json. כפתור נתוני הבדיקה מאפשר לראות חישוב אמיתי בלי תלות בחיבור החיפוש החי.

## מגבלות לפני שימוש ציבורי

זהו ניסוי, לא תחליף מאומת ל־Solar Fire. נשמרו פרופיל החישוב וספי הבדיקה המקוריים: Astronomy Engine 2.1.19, מיקומים גאוצנטריים טרופיים, DUT1=0 ומודל Delta T ברירת המחדל של המנוע; Swiss משמש רק לייחוס פיתוח ולא נכלל בקוד המוגש. מדגם passing אינו אימות לכל רגע ומיקום. Placidus בקווי רוחב קוטביים נדחה ללא שיטת בתים חלופית אוטומטית.

לפני פרסום נדרשות בדיקות קבלה עצמאיות של מפות מלאות מול נתוני ייחוס, בדיקת השירות החי בדפדפן בעל אמון תעודות תקין, אימות אזור הזמן למיקומים היסטוריים רגישים, בדיקות נגישות ודפדפנים נוספים ובחינת תנאי ספק חיפוש הערים לשימוש המתוכנן. חישוב Astronomy Engine ברישיון MIT אינו מסד נתונים היסטורי של רישומי לידה. אין לבצע Push שעלול להפעיל פריסת Netlify בלי לבדוק את הגדרות פריסת הענפים.
